# Research Publication / Conference / Festival / Residency Map
_Last updated: 2026-04-10_

This markdown file is designed as a structured source file for an AI agent or static-site generator.
It combines:

1. **Relevant journals**
2. **Conferences / symposia / workshops**
3. **Festivals / prizes / residencies / open calls**
4. **Known deadlines for 2026 where officially verified**
5. **Deadline status labels** for venues without a current fixed CFP

Legend for deadline fields:
- **fixed** = exact current deadline verified on an official page
- **rolling** = no fixed deadline / continuous submission
- **seasonal-check** = no current exact deadline verified, but there is a recurring annual or seasonal call pattern
- **special-issue-based** = publication accepts work, but themed calls vary
- **unknown-current** = relevant venue, but no current deadline was verified when this file was assembled
